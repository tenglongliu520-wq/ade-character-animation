# 阿德录制视频合成 · 2026-11-16

用户提供5段手机拍摄屏幕的阿德动作视频，要求据此合成。此次交付为视频剪辑，不是新生成的三维网格，也不代表实时口型、表情控制或完整360度转身已经完成。

## 成片

- `../assets/recording-composite-20261116/ade-recording-highlight-10s.mp4`：10秒精选，720×1280，30fps，300帧。
- `../assets/recording-composite-20261116/ade-recording-full.mp4`：72.2秒完整动作合成，720×1280，30fps，2166帧。
- 同目录 `edit-manifest.json`：源文件SHA256、入出点、成片参数及校验值。

顺序为正面待机、侧向迈步、摆臂、身体与手势动作、抬手收尾。每版均使用全部5个来源。精选版各取2秒，保留原速。完整版本保留较长动作段，去掉开头结尾的部分操作时间。

裁去底部控制区，完整保留水平视野；第二个来源在后段有画面缩放，因此另用1024像素裁切高度，其余1120像素。补足为竖版720×1280，H.264/yuv420p，faststart。切换时使用2帧黑场淡入淡出，不做人物交叠、插帧或循环拖影。去除全部原始麦克风声音，无配乐，不接入或改动现有I声线。

## 来源与实际限制

- 来源为用户于本轮提供的5个MP4。原微信临时路径在检查后失效，从同月持久视频目录找到5个等字节大小副本；逐一抽取1.5秒画面，与此前抽取画面进行逐像素比对，全部一致后复制到本地制作目录。
- 原视频与个人目录路径不放入公开仓库；公开同步裁切后的无声成片、合成脚本和说明。
- 源视频为屏幕拍摄，原有亮度、摩尔纹、局部模糊、鼠标指针、镜头晃动、衣袖和衣摆的模型变形仍可能可见。剪辑不能修复原模型骨骼、创造没有录到的动作或恢复模型文件。
- 阿德角色由用户提供并指示制作；三维预览来自用户Meshy账号。本轮沿用用户先前接受的CC BY 4.0条件，使用或再分发需保留适用署名和许可说明。此处并未新增授权判断。Meshy工作台：https://www.meshy.ai/ 。许可：https://creativecommons.org/licenses/by/4.0/ 。
- 网站版本及语音仓库未改动。

## 复现

安装 `imageio-ffmpeg` 后运行：

```powershell
python tools/compose_recordings.py --source-dir PATH_TO_FIVE_RECORDINGS --output-dir PATH_TO_OUTPUTS
```

五个输入文件名与剪辑点见脚本及manifest。脚本检查成片时长、帧数并完整解码所有帧；成片抽帧另作人工画面检查。
