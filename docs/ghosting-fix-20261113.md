# 重影修复 · 2026-11-13

原因：旧渲染对相邻两个动作方向帧做透明交叉淡化，并在动作起止叠加待机立绘，产生多个轮廓。

修复：动作期间直接返回单个不透明动作帧，不再绘制底下的待机角色，也不叠画相邻帧。加载时以alpha轮廓测量九格边界，按相同高度、脚底基线和水平中心对齐；方向帧之间通过小幅宽度缓动减少硬切感。动画循环改为60fps上限，页面后台或暂停时仍停止。素材仍为既有二维八方向，未宣称是新增连续三维帧。

回归验证覆盖动作进入、完整动作、退出三个阶段，每帧只有一次人物drawImage且alpha=1；主站相关24项检查通过。语音和动作联动消息格式没有改动，本轮仅更新动画仓库。
