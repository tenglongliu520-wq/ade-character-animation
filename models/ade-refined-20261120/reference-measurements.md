# 录屏对照约束

本轮以同一正面录屏帧为尺寸基准，兼看两张斜侧帧；没有用上一版的衣身继续微调。正面原帧为720×950，人物中心约x302、鞋底y915。制作映射为 x=(像素x−302)/376，z=(915−像素y)/376。渲染相机是同高度的水平正交相机，800×950、ortho_scale2.526；比较时原帧水平平移98像素即可对齐。

人工观察取点，存在数像素误差，不是原模型精确测量：

| 部位 | 参考位置或范围 | 本轮约束 |
| --- | --- | --- |
| 顶部帽饰 | y50左右 | 全高约2.30 |
| 眼睛 | y327左右，左右中心x249/346 | 眼高约1.56，中心距约.26 |
| 下巴 | y400左右 | 下巴约1.36 |
| 领口/肩部 | y410–450 | 领口约1.32，圆顺斜肩 |
| 腰带 | y520–548 | 腰带约.99–1.05，细窄深绿 |
| 袖口 | y620–655 | 低垂袖口约.74，手指继续向下 |
| 外衣下摆 | y790–810 | 外衣下摆约.30，前襟边向两侧展开 |
| 内衣下摆 | y825左右 | 内衣约.235，遮盖大部分裤腿 |
| 鞋底 | y910–915 | 只留窄浅色底边 |

录屏中人物姿态、透视与动作不同，斜侧对照主要检查眼球/脸颊体积、肩袖走势、衣长和发带位置。不能用这几处取点或格式校验直接宣布用户认可。
