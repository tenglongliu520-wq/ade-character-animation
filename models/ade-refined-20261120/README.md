# 阿德继续建模 · 录屏形体修订 · 2026-11-20

用户再次表示不满意上一轮模型，要求继续对照录屏建模。本目录是新一轮实际建模结果，**仍需用户外观验收，不作为最终完成或首页接入版本**。

## 本轮实际变化

- 根据录屏中的肩、袖口、腰带和衣摆高度，重建衣身与袖子，使用连续曲面形成斜肩和下垂钟形袖；没有继续沿用上一版的衣身网格。
- 缩小白色内领、将腰带提到录屏对应位置、延长内衣遮盖裤腿；改为窄浅色鞋底，并补充竹纹衣料和腰带上的浅色花扣。
- 眼白、虹膜、瞳孔、高光、眼皮、眉毛、鼻与微笑均为独立曲面或实体网格。眼部曲面随脸部弯曲，取代上一轮的整脸五官投射。面部贴图只含肤色和腮红。
- 继续保留已生成的层叠头发体积，修补裁切边界，补连续头发底层；帽饰和发带改为新建的浅青色布片。

头发颜色取自录屏，后脑细节、布纹布局和遮挡区域仍含推断。服装、脸和配饰由脚本重建，不是原 Meshy 模型恢复。当前独立眼部是贴合面部的曲面网格，不是完整眼窝/眼球解剖结构。

## 预览

运行 `python preview.py`，打开 http://127.0.0.1:4195/ 。正面、右侧、左侧按钮会同时切换录屏参考与模型观察角度。模型支持拖动旋转和缩放。录屏正在动作中，本站姿模型与参考姿态、角度并非完全一致。

`comparison.jpg` 为正面三版对照；`multi-view-comparison.jpg` 为多角度录屏对照。所有模型图片都是当前GLB对应场景的真实渲染，不是生成效果图。`preview-evidence.jpg` 是实际网页加载截图。

## 重建与检查

Python3.11环境：bpy4.5.3、Pillow13、numpy1.26.4。依次运行 `python prepare_textures.py`、`python build_refined.py`、`python verify_candidate.py`、`python make_comparison.py`。这些脚本只重写本目录生成物；原始输入 `source-geometry.glb` 和三张录屏帧保持原样。

公共仓库包含源脚本、输入网格、贴图和GLB；可编辑 `ade.blend` 保存在本地制作目录，遵守现有忽略规则不提交。`manifest.json` 与 `provenance.json` 记录文件哈希和来源。Three.js版本/许可见vendor。格式校验运行 `npm run validate:gltf`，输出见 `gltf-validation.json`。

本轮仍是未绑定的外观修订：没有动作、眨眼或嘴型控制，未替换首页，也没有语音接口改动。格式或结构检查不能代替形象验收，真实手机性能尚未测试。
