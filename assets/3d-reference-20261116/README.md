## 使用方式

单图转三维时，使用 `ade-hanfu-apose-front.png`，不要将整张三面图送入单人单图建模接口，避免被重建为三个人。三面图作为人工修整和侧背面核对参考。若使用多视角建模接口，须先准备独立且相互一致的单视角输入，查验实时参数要求后再提交。

生成网格后必须检查：头部与躯干厚度、完整材质、衣袖与手臂分离、双腿分离、背面无多余五官。自动骨骼绑定不保证大头和宽袖角色变形正确；面部眨眼、微笑和口型需另行制作及验收。
